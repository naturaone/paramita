## 📌 專案簡介

知足天是一套以「人人自主」為核心的思想藍圖。
本倉庫負責將此藍圖落實為可運行的技術系統。

**核心目標**：建立一個以「人人自主」為核心價值的文明新範式之技術基礎設施。

# Tusita · Technical Implementation

> This repository is the technical implementation of the Tusita blueprint.
> Technologists and developers are welcome to participate.


## 📌 Overview

Tusita is a blueprint centered on the principle of **"autonomy for all"**.
This repository is responsible for realizing that blueprint as a working technical system.

**Core Mission**: To build the technological infrastructure for a new civilizational paradigm rooted in the value of **"autonomy for all"**.


## 🏛️ Governance

- The system architecture is fixed and not open to modification. Requests involving architectural changes will not be accepted.
- Technologists implement the system according to the system specification.


## 📖 System Specification

👉 [Download System Design Document (PDF)](./SYSTEM_DESIGN.pdf)

This document is closed and not open to modification.
All technical implementation must be based on this document.

## 🤝 How to Contribute

1. Fork this repository
2. Create your feature branch
3. Submit a Pull Request
4. 🤖 **CLA Bot Check**: After submitting a PR, the CLA Assistant bot will automatically comment in the PR and guide you to sign the CLA
5. **Sign the CLA**: Click the link provided by the bot, read and agree to the [CLA.md](./CLA.md)
6. Once signed, the PR status automatically updates to mergeable
7. Merged after review by the core team

⚠️ **Notes**:
- Pull Requests are limited to code implementation and must not involve system architecture changes.
- **All contributors must sign the CLA via the CLA bot in the PR.** PRs without a signed CLA will not be merged.
- First-time contributors need to sign; subsequent PRs are automatically recognized.

For details, see [CONTRIBUTING.md](./CONTRIBUTING.md) and [CLA.md](./CLA.md).
